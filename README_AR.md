# StreamView - منصة بث احترافية للأفلام والمسلسلات

## 📋 نظرة عامة على المشروع

منصة بث احترافية مع واجهة مستخدم حديثة (UI/UX) تتميز بتصميم غلاسمورفيزم جذاب وسهلة الاستخدام. المشروع يوفر:

### ✨ المميزات الرئيسية:
- 🎬 عرض الأفلام والمسلسلات والمنوعات
- 🔍 بحث فوري في جميع المحتوى
- 📱 تصميم متجاوب يدعم جميع الأجهزة
- 🎨 تصميم غلاسمورفيزم حديث مع تدرجات ملونة
- ♾️ تحميل لا نهائي للمحتوى (Infinite Scroll)
- 🌙 نمط داكن احترافي (مثل Netflix)
- 🎯 واجهة عربية كاملة (RTL)
- 📊 تصنيفات متعددة للمحتوى

## 🚀 كيفية البدء

### المتطلبات:
- Node.js 18+ مثبت
- npm أو yarn (مدير الحزم)

### خطوات التثبيت والتشغيل:

1. **انتقل إلى مجلد المشروع:**
   ```bash
   cd d:\Mov\streaming-app
   ```

2. **تثبيت المكتبات:**
   ```bash
   npm install
   ```

3. **تشغيل خادم التطوير:**
   ```bash
   npm run dev
   ```

4. **افتح المتصفح:**
   - اذهب إلى: `http://localhost:3000`

5. **لبناء للإنتاج:**
   ```bash
   npm run build
   npm start
   ```

## 📱 الصفحات والميزات

### 1. **الصفحة الرئيسية** (`/`)
- عرض البحث البارز
- ثلاثة أقسام: أشهر الأفلام، أفضل المسلسلات، المنوعات
- 10 عناصر من كل فئة في عرض أفقي
- زر "عرض الكل" للانتقال إلى صفحات الفئات

### 2. **صفحة الأفلام** (`/movies`)
- شبكة كاملة لجميع الأفلام
- بحث فوري داخل الأفلام فقط
- تحميل لا نهائي عند الوصول لنهاية الصفحة
- شبكة متجاوبة: عمود واحد (موبايل) → عمودين (تابلت) → 4 أعمدة (ديسكتوب)

### 3. **صفحة المسلسلات** (`/series`)
- نفس الميزات كصفحة الأفلام ولكن للمسلسلات

### 4. **صفحة المنوعات** (`/miscellaneous`)
- نفس الميزات كصفحة الأفلام ولكن للمحتوى المتنوع

### 5. **صفحة البحث** (`/search?q=...`)
- البحث الشامل في جميع المحتوى
- البحث يشمل العنوان والوصف
- عرض النتائج بشكل متجاوب

## 🎨 التصميم والأنماط

### Glassmorphism Design:
- أوراق شفافة مع تأثير الضبابية
- تدرجات ملونة (أحمر وردي → أحمر)
- ألوان أساسية:
  - **Primary**: `#1a1a2e` (أسود عميق)
  - **Secondary**: `#16213e` (أزرق داكن)
  - **Accent**: `#e94560` (أحمر وردي)
  - **Accent Light**: `#ff6b7a` (أحمر فاتح)

### التجاوب (Responsive):
- **موبايل** (320px - 640px): شبكة عمود واحد، قائمة هامبرجر
- **تابلت** (641px - 1024px): شبكة عمودين
- **ديسكتوب** (1025px+): شبكة 4 أعمدة، قائمة ملكية كاملة

## 🔍 ميزة البحث

### البحث الفوري:
```typescript
// يتم البحث عن:
- عنوان المحتوى (case-insensitive)
- وصف المحتوى
- عند الكتابة مباشرة (debounced)
```

### أنواع البحث:
1. **من الصفحة الرئيسية**: يعيد التوجيه إلى `/search?q=...`
2. **من صفحات الفئات**: يصفي المحتوى محلياً
3. **من صفحة البحث**: يحدّث النتائج تلقائياً

## ∞ التحميل اللا نهائي (Infinite Scroll)

- يتم تحميل 20 عنصر في البداية
- عند الوصول لأسفل الصفحة (300px من النهاية)، يتم تحميل 20 عنصر إضافي
- مؤشر تحميل يظهر أثناء جلب العناصر الجديدة
- رسالة نهائية عند تحميل جميع العناصر

## 🔧 البيانات والمحتوى

### بيانات العينة (Mock Data):

- **المسلسلات**: 12 مسلسل

### بيانات المحتوى:
```typescript
interface Content {
  id: string;           // معرّف فريد

  rating: number;       // التقييم (0-10)
  year: number;         // سنة الإنتاج
  genre: string;        // النوع
  description: string;  // الوصف
}
```

### التبديل إلى API حقيقي:
1. استبدل `mockData.ts` بدوال تجلب من خادم حقيقي
2. المكونات لا تحتاج إلى تعديل - فقط اجعل البيانات تطابق نفس الإنترفيس

## 🎯 المكونات الرئيسية

### Header (شريط التنقل)
- شعار مع أيقونة
- روابط التنقل (الرئيسية،  الأفلام، المسلسلات، المنوعات)
- عنصر البحث
- قائمة هامبرجر للموبايل
- تتبع الحالة النشطة

### ContentCard (بطاقة المحتوى)
- صورة المحتوى
- تأثيرات عند التمرير (hover)
- عرض التقييم والسنة عند التمرير
- قابلة للنقر (للتوسع المستقبلي)

### SearchBar (عنصر البحث)
- بحث متزامن مع الكتابة
- يدعم إعادة التوجيه التلقائي
- قابل للتخصيص من خلال props

### ContentGrid (شبكة المحتوى)
- شبكة متجاوبة
- تحميل لا نهائي تلقائي
- مؤشر تحميل
- رسالة عند عدم وجود عناصر

### Footer (التذييل)
- روابط سريعة للصفحات
- روابط وسائل التواصل:
  - Facebook
  - Twitter
  - Instagram
  - YouTube
